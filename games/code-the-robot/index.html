🤔 How to play

  1. Tap the arrow tiles ⬆️⬇️⬅️➡️ to build a program — up to 12 steps.
  2. Press ▶ Run and watch the robot follow your steps to the ⭐.
  3. Bumped into a wall? 🧱 No problem — the step that went wrong stays highlighted. Tap it to remove it, fix your program, and run again!
  4. Use ⏭ Step to walk through your program one move at a time.
  5. Match the 🎯 best path for 3 stars. Nothing is saved — stars reset when you leave.

Keyboard: ↑ ↓ ← → add steps, Backspace removes the last one, Enter runs.
